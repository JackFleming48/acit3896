<h1>Exponentials</h1><br>
y = a * b^x<br>
the a * b^x part is what we care about, it is what makes it exponential. It can have more after like this:<br>
y = a * b^x + .....<br>
it is still exponential.<br><br>
Is y = 2x^3 exponential?<br>
1. Is there an exponent? Yes.<br>
2. Is this function exponential? No it is not.<br>
This is because of the position of the x. The independant variable is not in the exponent. If it is in the exponent position than it is.<br><br>
<h1>Logarithmic functions</h1><br>
y = log<sub>b</sub>(x)<br>
Like the exponential, there are more things that can come after like this.<br>
y = log<sub>b</sub>(x) + .....<br>
SO LONG AS what we are adding is a constant. Cannot add anything other than a constant number.
