Polynomials


y = ax^i
+ bx^j
+ cx^k
+ ....
1 is a valid power so it makes this a linear function.
can also be to the power of 0 which is the same as saying just the coefficient.

Exponentials


y = a * b^x
the a * b^x part is what we care about, it is what makes it exponential. It can have more after like this:
y = a * b^x + .....
it is still exponential.

Is y = 2x^3 exponential?
1. Is there an exponent? Yes.
2. Is this function exponential? No it is not.
This is because of the position of the x. The independant variable is not in the exponent. If it is in the exponent position than it is.

Logarithmic functions


y = logb(x)
Like the exponential, there are more things that can come after like this.
y = logb(x) + .....
SO LONG AS what we are adding is a constant. Cannot add anything other than a constant number.
